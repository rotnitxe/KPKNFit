## Alcance observado en código

El flujo existente ya dispone de lector XLSX, ODS, CSV, TSV, DOCX, texto y Markdown, OCR local, editor compartido y persistencia durable. La entrada URL no está conectada y el lector rechaza XLS antiguo. El modelo del borrador conserva una unidad global, no una por fila. El código actual declara Room 37.

La inspección estática y las pruebas JVM no acreditan las metas de OCR ni compatibilidad XLS en dispositivos. Las pruebas OCR existentes incluyen reconocedores simulados; la aceptación solicitada requiere muestras y mediciones físicas por separado.
