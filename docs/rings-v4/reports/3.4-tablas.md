# Tablas antes y después · Paquete 3.4 (Rendimiento bilateral EKF v4)

## 1. Contratos de Mediana, Reloj y Bilateralidad

| Concepto | Antes (EMA legado / 3.3 suspendido) | Después (Paquete 3.4 · EKF v4) |
|---|---|---|
| **Referencia base** | `PerformanceRangeCalculator.computeRange` (media RMS exponencialmente ponderada hacia el último log) | **Mediana de las últimas 3 sesiones comparables ANTERIORES** (excluida la sesión medida). En e1RM: estimación agregada `sessionErm` de cada sesión. En ΔRPE: mediana de sets equivalentes por sesión, y luego mediana de las 3 referencias. |
| **Robustez** | Series aplanadas (10 series en una sesión inflaban su peso) | **Una estimación por sesión**; duplicar series no altera la mediana. Sesiones 100, 100, 160 dan mediana **100** (no 120). |
| **Ordenación** | Consumía orden del DAO (DESC sin ordenar) | Ordenación causal **ASC** estricta con desempate estable por `id`. Logs futuros al inicio de sesión medida: **0 influencia**. |
| **Reloj causal** | `nowMs = System.currentTimeMillis()` al invocar el ViewModel | Separación estricta: `observationAtMs` (inicio real) para predicción, Δt y corte causal; `processingNowMs` solo para expiración. Procesar a 0 h vs 5 h: **idéntico**. |
| **Progreso (ν > 0)** | Se descartaba por completo (`progression_not_learned`), sesgando el motor a τ más lentos | **Bilateralidad:** ν > 0 aporta peso **0,5** (media información); σ_efectiva = σ_base / √0,5. τ no sube (acorta o mantiene). |
| **Retroceso (ν < 0)** | Inversión de estrés sesgada con actualización EMA | ν < 0 aporta peso **1,0**; σ_efectiva = σ_base. τ no baja (alarga o mantiene). |
| **Gate de admisión** | Umbral paralelo de 8 puntos (`NOISE_THRESHOLD = 8`) | **Gate común EKF 3.2**: zona muerta 3,0 puntos, saturación ≥ 99,5, ventana 8–336 h, piso/bloqueo y sensibilidad \|H\| ≥ 0,1. |

## 4. Comparativa de Casos Numéricos

### Caso A: 3 referencias con e1RM 90, 100, 110 y sesión actual 100
- **Antes (RangeCalculator):** rms ponderado exponencial hacia el más reciente (110) ≈ 104,1 → ratio = 100 / 104,1 = 0,9606 → implied ≈ 84 → sorpresa distorsionada por recencia.
- **Después (Mediana de 3 sesiones):** mediana([90, 100, 110]) = **100,0** → ratio = 100 / 100 = 1,0000 → implied = **98** → evaluación centrada y no sesgada por el último valor aislado.

### Caso B: Robustez ante outlier (100, 100, 160) y sesión actual 100
- **Media aritmética / EMA:** (100 + 100 + 160) / 3 = 120,0 → ratio 100 / 120 = 0,833 → falso colapso de rendimiento.
- **Mediana v4:** mediana([100, 100, 160]) = **100,0** → ratio 100 / 100 = 1,000 → robustez absoluta ante registros anómalos o picos únicos.

### Caso C: Inversión del orden en historial (ASC vs DESC vs Permutado)
- **Diferencia en baseline:** `0,0` (|baseline_asc - baseline_desc| ≤ 10⁻¹²).
- **Diferencia en y implícito:** `0,0` (≤ 10⁻¹²).
- **Diferencia en σ efectiva:** `0,0` (≤ 10⁻¹²).
- **Diferencia en posterior de Kalman (mean y variance):** `0,0` (≤ 10⁻¹²).
