   playing: Boolean, modifier)`:
   - Media3 `ExoPlayer` creado una vez (`remember`), `REPEAT_MODE_ONE`, volumen 0, `PlayerView` en `AndroidView` con `useController = false` y
     `RESIZE_MODE_ZOOM`; `release()` en `onDispose`.

2. En `WelcomeSceneOf`, cada página usa el vídeo si el recurso existe (`res/raw/welcome_{entreno,nutricion,rings}.mp4` y
   `res/drawable-nodpi/welcome_{…}_poster.webp`); mientras no existan, la escena Canvas de hoy (así se puede integrar antes de grabar). Mantén las
   etiquetas `welcome-*`.
