# I11a · Iconos KPKN Line (2026-10-13)

Worktree y rama: los del mensaje de lanzamiento (salen de `feat/wizard-v3`). Lee antes `docs/wizard-v3/BRIEF_COMUN.md` y
`docs/design/KPKN_UI_V2.md` (§4 Iconos). Este paquete SOLO crea archivos nuevos: no cambia ninguna pantalla. Otros paquetes los
aplicarán.

## Por qué
Home mezcla cuatro estilos de icono:
- la casa rellena de Material;
- una «H» como mancuerna;
- una manzana rellena;
- un bíceps de dibujo animado;
- además, el persona y el play de Material y un libro fino.

El usuario pidió pulir iconos y símbolos con un listón de nivel mundial. Hace falta UN set coherente, propio de KPKN.

## Qué haces

     `strokeLineCap = StrokeCap.Round`, `strokeLineJoin = StrokeJoin.Round` y `fill = null`. El color lo pone `Icon(tint = …)`.
