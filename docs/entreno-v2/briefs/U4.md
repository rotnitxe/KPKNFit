## 1. `GoalProfileList` — «¿Cuál es tu objetivo?»
```kotlin
@Composable fun GoalProfileList(
    selected: TrainingGoalProfile?,
    blockedReasons: Map<TrainingGoalProfile, String>,   // perfil → «Necesita barra, rack y banco»; ausente = disponible
    onSelect: (TrainingGoalProfile) -> Unit,
    onBlockedTap: (TrainingGoalProfile) -> Unit,         // tocar uno bloqueado (el dueño enseña cómo cambiar el material)
    modifier: Modifier = Modifier,
)
```
Dos tramos sobre la página, sin tarjetas: **«Generales»** (`TrainingGoalProfile.general`: 3) y **«Específicos»** (`TrainingGoalProfile.specific`: 7, con la leyenda «dependen de tu material»). Cada perfil es una fila de lista sin caja
con filete inferior: a la izquierda un **símbolo animado** de ~56 dp de su disciplina (barra y discos; barra con kettlebell para híbrido; figura con corazón y pulso para funcional; anillas para calistenia; barra con discos grandes para powerlifting;
mancuerna y silueta de espalda para culturismo; barra olímpica sobre la cabeza para halterofilia; mano y antebrazo para armwrestling; piedra y yugo para strongman; barra con mancuerna para powerbuilding), a la derecha el nombre (Syne 17) y una línea
(`TrainingGoalProfile.tagline`, 13–14 sp). Seleccionado: el símbolo se enciende con el acento de su disciplina y se anima en bucle, el nombre en tinta plena y una marca de «hecho» que se dibuja; no seleccionado: trazo tenue estático. Bloqueado: todo al ~40 %,
con la razón en una línea (`blockedReasons`, color `WizardColors.danger` suave, 13 sp) y sin poder seleccionarse (tocar llama `onBlockedTap`). `testTag("setup-goal-<NAME>")`, `Role.RadioButton`, estado y razón accesibles.
Acentos por disciplina (úsalos también en las portadas): powerlifting `#F49A6E`, powerbuilding `#F7CF73`, culturismo `#C9B8FF`, calistenia `#43D18C`, halterofilia `#8FB2FF`, armwrestling `#F49A6E`, strongman `#F7CF73`, generales tinta cálida con un detalle verde.

## 2. Modelos de datos (`PlanModels.kt`)
```kotlin
data class PlanCardModel(
    val id: String, val title: String, val kicker: String,          // «Hecho a tu medida», «Jim Wendler», «Versión inicial»…

    val card: PlanCardModel, val description: String,

```
## 3. `PlanCover` — la portada
`PlanCover(model: PlanCardModel, modifier, animate: Boolean = false)`: portada procedural tipo cartel, proporción 3:4 (tarjeta del carrusel) y banda ancha (cabecera del detalle): campo oscuro con un degradado muy suave hacia el acento de la
disciplina (permitido aquí: es una imagen, no un borde), una ilustración de línea grande y reconocible de la disciplina (la misma familia visual de los símbolos de `GoalProfileList`, a mayor tamaño y con un toque animado leve si `animate`), el kicker en Inter
mayúsculas, el título en Syne ExtraBold (hasta 3 líneas) y abajo tres datos (días · minutos · nivel). Variación por `coverSeed` (ángulo del degradado, posición de la ilustración) para que los planes de una misma disciplina no sean idénticos. Nada de texto
sobre una zona de bajo contraste (compruébalo).

## 4. `PlanPreparingOverlay` — la animación «estamos preparando tu programa»
```kotlin
enum class PlanPreparingVariant { GENERAL, DISCIPLINE }
@Composable fun PlanPreparingOverlay(
    variant: PlanPreparingVariant,
    profile: TrainingGoalProfile?,
    ready: Boolean,                       // el motor ya tiene el resultado
    onAnimationDone: () -> Unit,          // la animación mínima terminó Y ready == true: el dueño muestra el resultado
    modifier: Modifier = Modifier,
)
```
`Dialog` a pantalla completa con el patrón de `ModuleCompleteOverlay` (desenfoque del sistema si hay, velo opaco si no; no se cierra tocando fuera). Textos: GENERAL = «Estamos preparando tu programa personalizado», DISCIPLINE = «Seleccionando programas para tu disciplina»
(con el nombre de la disciplina). Animación (≥ 2,6 s, sin fin visible mientras `ready == false`): la Torre de la marca se arma y, en una fila de cinco etapas que se van encendiendo («Tu material», «Tus días», «Tu tiempo», «Tus músculos», «Tus ejercicios» /
en DISCIPLINE: «Tu disciplina», «Tu material», «Tus días», «Tu nivel», «Los mejores planes»), una guía luminosa las recorre; al terminar todas y estar `ready`, un destello discreto y `onAnimationDone`. Con movimiento reducido: estado final inmediato.
`testTag("setup-plan-preparing")`.

## 5. `PlanCarousel` — elegir entre planes de autor
```kotlin
@Composable fun PlanCarousel(
    cards: List<PlanCardModel>, selectedId: String?, onSelect: (String) -> Unit, onOpen: (String) -> Unit,
    modifier: Modifier = Modifier,
)
```
`HorizontalPager` con la tarjeta central grande (portada 3:4) y las vecinas asomando y atenuadas/escaladas (parallax suave de la ilustración al deslizar); debajo del centro: el blurb y dos acciones de texto (sin caja): «Ver detalles» (`onOpen`) y «Elegir» (`onSelect`); la elegida lleva una marca de «hecho» sobre la portada.
Indicador de páginas de puntos. Con una sola tarjeta se muestra centrada sin pager. `testTag("setup-plan-card-<id>")`, semántica de selección.

## 6. `PlanDetailOverlay` — el detalle bien diseñado
```kotlin
@Composable fun PlanDetailOverlay(model: PlanDetailModel, selected: Boolean, onChoose: () -> Unit, onClose: () -> Unit)
```
Hoja a pantalla completa (Dialog con desenfoque) que se abre con una transición de la portada (la cabecera ocupa el ancho, parallax al hacer scroll). Contenido, en este orden, todo sobre la página negra sin cajas: portada; descripción (≤ 4 líneas, expandible); **Ejercicios principales** (hasta 6, como lista de línea con
un símbolo de patrón); **Estructura** (los bloques como una línea de tiempo horizontal con su etiqueta y semanas); **Tu semana** (los 7 días como círculos: los de entreno llevan su título corto, minutos y un punto en el día principal); **Por qué este plan** (las `reasons`);
notas honestas (`notes`, p. ej. «versión inicial») y la atribución; una frase fija y amable: «Podrás modificarlo libremente después.»; botón principal «Elegir este programa» (o «Programa elegido» si `selected`) y cerrar. `testTag("setup-plan-detail")`.
