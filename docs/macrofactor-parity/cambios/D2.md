# Cambios visibles · D2 (Hábitos)

Filas para las notas de versión. El orquestador las pasa a `CAMBIOS_VISIBLES.md`; este archivo es de la pista D2.

| Pantalla | Qué cambia | Antes → después | Por qué |
|---|---|---|---|
| Perfil | Tarjeta nueva «Hábitos» con el botón «Ver hábitos» | Antes: no había acceso a rachas de hábitos → después: tarjeta con enlace a la pantalla Hábitos | Rachas de comidas, pesaje y entrenos (C7 del informe) |
| Hábitos (nueva, ruta `habits`) | Selector Comidas, Pesaje y Entreno; racha actual y mejor en días o semanas; calendario de las últimas 53 semanas con descripción por día | Antes: no existía la pantalla → después: rachas y calendario de los tres hábitos | C7 del informe; el calendario se lee sin depender del color |
| Enlace `kpkn://habits` (también `kpkn://habitos`) | Abre la pantalla Hábitos | Antes: el enlace no tenía ruta → después: abre Hábitos | Entrada directa desde fuera de la app |
