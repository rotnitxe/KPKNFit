# Cambios visibles · N3

| Pantalla | Qué cambia | Antes → después | Por qué |
|---|---|---|---|
| Calibración · revisión semanal | Desplazamiento al módulo | Al pulsar «Continuar», «Paso anterior» o «Empezar» la lista se quedaba donde estaba y el módulo nuevo aparecía a media pantalla → la lista se desplaza (animada; directa con movimiento reducido) hasta el inicio del módulo, con «Paso n de N» y su barra arriba. No se mueve si ya lo tienes arriba | No tener que subir a leer el título de cada paso |
| Calibración · módulos «Tu tendencia de peso» y «Tu objetivo para mañana» | Gasto estimado sin repetir | Cada módulo repetía estado, cifra, banda, datos, tendencia y la nota «Es una estimación, no una medición» que la página ya muestra en «Gasto estimado» → dentro de la calibración, el pesaje muestra solo los pesajes usados y la tendencia (+ «Registrar pesaje») y el objetivo solo antes/después, evidencia y botones. La vista previa suelta conserva el resumen completo | Mostrar cada dato una sola vez |
| Registrar comida · pestaña Buscar | Escáner de códigos de barras (NUEVO) | No había forma de buscar por código → icono de código de barras junto al campo de búsqueda: abre un escáner a pantalla completa (cámara con ML Kit empaquetado, sin red), acepta un código tras 2 lecturas iguales y seguidas, vibra una vez y apaga la cámara. Sin permiso de cámara (o con la cámara rota) queda solo la entrada manual, con el dígito de control validado | Más rápido y fiable para productos envasados; nada sale del teléfono |
| Escáner · producto encontrado | Confirmación con el origen del dato (NUEVO) | — → nombre, marca, «Dato propio» o «Dato de la base global», banderas de calidad y el selector de gramos del cajón; «Agregar a la comida» lo pasa al registro por el mismo camino que una fila del buscador. Con nutrientes incompletos o no verificables no se puede agregar y se ofrece crear un alimento propio | No se inventan macros |
| Escáner · producto desconocido | «No tengo este producto» (NUEVO) | — → botón «Crear alimento propio con este código» (formulario con el código puesto) y «Probar otro» | La próxima vez que se escanee, se reconoce |
| Registrar comida · pestaña Buscar | Alimentos propios (NUEVO) | No había pantalla para crearlos ni editarlos → «Crear alimento propio» bajo el buscador y «Editar alimento propio» bajo cada resultado propio: nombre, marca, código, porción (g o ml), base «por porción» o «por 100 g», kcal, proteína, carbohidratos, grasas y fibra/azúcar/sodio opcionales; avisa (sin bloquear) si las kcal no cuadran con los macros; permite eliminar con confirmación | Cerrar el hueco de los productos que no están en la base |
| Alimentos propios | Guardado durable | `addCustomFood` publicaba antes de guardar → `saveCustomFood` espera a Room y solo entonces publica; un fallo avisa y no deja el alimento a medias. `addCustomFood` (caché de la IA) no cambia | Evita el falso éxito |
