# APK base release KPKN Beta 14.8

## Rutas
- android-native/app/build.gradle.kts: versionName 14.8 y versionCode 33.
- releases/KPKN Beta 14.8.apk: artefacto firmado.

## Impacto
Compilar variante baseRelease para teléfonos y baseDebug para emulador Pixel Pro. Instalar herramientas Android/JDK necesarias. No cambiar lógica del producto. Usuario autorizó generar nueva clave: RSA4096 PKCS12 persistente, secretos en keystore.properties ignorado por git y permisos0600. Build carga firma desde propiedades privadas.

## Pruebas
assembleBaseRelease BUILD SUCCESSFUL; verificar apksigner, zipalign, metadatos y SHA256. Instalar y abrir app en emulador.

## Riesgos
La clave histórica no está en el repositorio. Nueva firma autorizada: válida para instalación limpia pero no actualización de otra firma. Mantener cualquier clave generada privada, fuera de git.
